# NEXO — versões prontas

Daqui o NEXO baixa as próprias atualizações. Não precisa fazer nada: ele procura sozinho ao abrir e a cada 6 horas.

- **Baixar a versão mais nova na mão:** clique em [`NEXO.exe`](NEXO.exe) e depois no botão de download (Download raw file).
- `versao.json`: qual é a versão atual (o NEXO lê este arquivo).
- `versoes/`: todas as versões publicadas, para voltar a uma anterior se precisar.
- `LEIA-ME.txt`: o que tem em cada versão.
